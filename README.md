# 🎮 Unity Classic Remakes

Projeto pessoal focado na recriação de jogos clássicos do NES utilizando **Unity**.
O objetivo é estudar **game design, mecânicas clássicas e arquitetura de jogos** através da prática.

## 🚀 Sobre o projeto

Este repositório reúne remakes de jogos clássicos com foco em:

* 🎮 Recriar mecânicas fiéis aos jogos originais
* 🧠 Estudo de game design clássico
* ⚙️ Prática de arquitetura e organização de código em Unity
* 🎨 Exploração de pixel art e animação
* 🔊 Implementação de áudio e feedbacks

## 🕹️ Jogos em desenvolvimento

### 🏁 Excitebike (NES)

* ✔️ Movimento básico da moto
* ✔️ Sistema de aceleração e freio
* 🔄 Sistema de obstáculos (em progresso)
* 🔄 Física de salto e colisão
